## 🚀 Featured Projects

### Warehouse Mobile Manipulator

**ROS 2 · C++ · Python · Nav2 · MoveIt · Gazebo · OpenCV**

A robotics system focused on mobile manipulation within a simulated warehouse environment.

The project brings together robotic navigation, perception, and manipulation in a modular software architecture.

**Engineering components:**

* ROS 2-based software organisation.
* Autonomous navigation using Nav2.
* Motion planning and manipulation using MoveIt.
* Object detection and visual perception.
* Navigation-to-manipulation task integration.
* Simulation and behavioural testing in Gazebo.

**System objective:** Enable a robot to navigate a warehouse environment, identify objects, and execute pick-and-place workflows.

[Explore my repositories](https://github.com/OluomaOji/)

### Smart Racket Sports System

**Computer Vision · Machine Learning · IMU · Sensor Fusion · Data Engineering**

An intelligent sports technology MVP designed to analyse racket-sport movements and generate performance insights from multimodal data.

The system concept integrates:

* IMU telemetry for movement analysis.
* Video-based performance observation.
* Human pose estimation and computer vision.
* Machine learning for movement classification.
* Sensor-video synchronisation.
* Performance scoring and coaching insights.

I contributed to the development of the MVP and its technical architecture, exploring how sensor telemetry, video, and machine learning could be combined into an integrated performance analysis system.
